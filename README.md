# ElementsOfChaosMod
A Minecraft mod to allow you to research, combine, and create mystical substances with different properties
# Basics
This mod introduces the Fundamental Elements, of which everything is composed; these are conceptual substances which underly the Minecraftian world. 
Different items, mobs, and blocks have different amounts of different Elements. These elements lend different properties to substances. Some such Elements include:
* Botah, an Element that exists in items which fly or are lighter than air; things like feathers have a tiny bit of it, and elytras have a lot.
Botah gives jump-boosting or floating properties to substances.
* Agni, an Element that composes things which create fire or heat, like blaze rods, TNT, fire charges, but also things like flint, iron, and flint-and-steel.
Agni allows substances to produce fire or even explosions.
* Zolon, an Element composing things like wood, which catch fire easily, and fuel-type items. Zolon allows substances to generate energy for energy-type machines and causes them to be highly flammable.
* Borokhun, an Element that is found in water, various liquid things, and living beings.
Borokhun makes substances liquid.
* Puhor, an Element that is found in light-emitting blocks like redstone lamps and glowstone.
Puhor allows substances to emit light.
* Shakti, an Element that is found in mechanical objects, i.e. different kinds of pistons.
Shakti allows substances to push and move things.
* Kathinatva, an Element found in metals; the more of this an object has, the higher durability it has. Only metals and stronger items have it, like diamond, obsidian, etc.
Kathinatva makes substances solid and gives them durability when used as tools.
* Hil, an Element found in rock and stone. Hil makes substances stronger when used as building materials.
* Guri, an Element found in falling blocks. Guri allows substances to fall.
* Bhari, an Element in maces and anvils. Bhari allows substance to be heavy, i.e. cause damage when falling; it allows substances to fall, like Guri.
* Zunga, an Element in weapons of various kinds. Zunga allows substances to generally cause greater damage.
* Sphotik, an Element found in sand, glass, and crystals. Sphotik allows substances to be visually transparent and have transparent properties.
* Xo, an Element found in undead mobs. Allows substances to give hunger when ingested. One of the Pieces of Life.
* Tez, an Element found in all mobs considered living. Allows substances to give healing.
* Omrit, an Element found in Withers, Ender Dragons, players, potions of healing, regeneration, etc. Allows substances to cause regeneration.
